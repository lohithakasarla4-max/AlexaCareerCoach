# Alexa Career Coach 🎙️

An AI-powered career coach and mock interviewer providing a simulated Alexa+ voice-first experience.

## Features
* **Resume & JD Matcher:** Evaluates resume alignment against job descriptions and provides missing keyword analysis.
* **Simulated Alexa+ Voice Interface:** Delivers natural voice-driven feedback and interview guidance.
* **Mock Technical Interviewer:** Asks role-specific technical questions and evaluates responses.

## Tech Stack
* **Language:** Python
* **Framework:** Streamlit
* **Track:** Alexa+ (Simulated Experience path)
